# AI 处理

Youtab 运行在 **Alpha v0.6** 上，这是 Youtab 托管的推理智能体。无需任何配置：登录
Youtab，Alpha 就已就绪。

## 你需要做什么

什么都不用做。Alpha v0.6 由 Youtab 预配、运维并承担费用。你不需要提供 API 密钥、
选择引擎或管理模型。登录就是全部的设置过程。

在 Chat 的 **Agent** 选择器中选择你想使用的智能体，或打开 **Agents** 应用查看你的
账户可用的全部智能体。

## 自带 API 密钥

Youtab 不提供自带密钥（BYOK）功能。你无法输入、上传、存储或配置任何提供商的 API
密钥；尝试携带密钥的请求会被服务端拒绝，而不仅仅是在界面上隐藏。

这是有意为之。Youtab 集中持有凭据、算力容量以及具备合同约束的数据保护条款，从而让
每个账户都获得同一条经过审核的处理路径，而不是由每位用户各自拼装。

如果你有依赖自有基础设施的企业或本地部署需求，请联系 Youtab —— 这属于在组织管理下
签约安排的事项，而非逐用户的设置项。

## 第三方处理

为了交付和运营本服务，Youtab 可能会使用经过严格甄选的第三方基础设施与 AI 处理服务
提供商。这些提供商须遵守适用的合同、保密、安全与数据保护要求。

Youtab 不公开哪一家提供商为哪一个智能体提供服务。智能体背后的引擎属于实现层面的
基础设施：它有版本、会在 Youtab 认为有必要时更换，把它固定写进公开文档会把一个运维
细节变成一项承诺。真正稳定、也是你应当依赖的，是智能体的公开身份 —— `alpha.v06`，
标签为 **Alpha v0.6** —— 以及其已记录的角色与能力。

关于 Youtab 如何处理你的数据的完整说明，请参阅
[服务条款](https://youtab.io/terms)与[隐私政策](https://youtab.io/privacy)。

## 本页面原先的内容

本页曾是一份推理提供商目录，以及为每一家提供商完成身份验证所需的环境变量。那反映的是
产品早期的形态：每位用户各自拼装自己的推理链路。Youtab 现在是托管服务，该目录描述的
是普通用户已不再拥有的能力，继续保留只会记录一套无法执行的配置步骤。

智能体身份、选择方式与能力的说明，请参阅
[配置智能体](../user-guide/configuring-models.md)。
